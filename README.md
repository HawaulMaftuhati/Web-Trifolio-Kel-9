# Project UTS 1 — GitHub Basics & Personal Portfolio

## 📌 Deskripsi Proyek

Proyek ini merupakan tugas Ujian Tengah Semester (UTS) mata kuliah **Sistem Basis Data** pada Program Studi Teknik Informatika, UIN Syarif Hidayatullah Jakarta.
