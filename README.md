# TrioFolio

Halaman utama yang menghubungkan tiga website portofolio anggota.

## Cara menggunakan
1. Buka `index.html` di browser untuk melihat tampilan.
2. Untuk memublikasikan lewat GitHub Pages, unggah `index.html` ke repository baru.
3. Buka repository → Settings → Pages.
4. Pada bagian Build and deployment, pilih Deploy from a branch, pilih branch `main` dan folder `/(root)`, lalu Save.
5. Setelah proses publikasi selesai, buka alamat website yang ditampilkan GitHub Pages.

Tautan anggota dapat diubah langsung di `index.html` jika diperlukan.
